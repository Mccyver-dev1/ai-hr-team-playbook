# AI HR Team Playbook

AI HR service model for end-to-end HR support.

## What this project is
A configurable catalog of AI HR specialist capabilities. Clients start with business pain points and select the specialist(s) and workflow(s) that solve those problems.

## What this project is not
- Not a fixed “17 AI employees” package.
- Not an Adecco product or advertisement.
- Not a replacement for human HR authority.
- Not a quotation based on human salary benchmarks.

## Initial specialist catalog
The current release starts with 17 specialist roles across five HR workstreams. The number is intentionally expandable.

## Market benchmark
Adecco Thailand Salary Guide 2026 is used only to understand real HR job families and market salary ranges. The benchmark is displayed in Thai Baht and kept separate from AI service pricing.

## Next implementation stages
- Client pain-point intake
- Agent selection and service configurator
- Per-client workflow configuration
- Feishu / HRIS integrations
- Knowledge base / RAG
- Authentication and permissions
- Audit logs and approval workflows
- Service pricing and ROI calculator
