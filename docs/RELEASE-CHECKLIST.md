# Release Checklist v0.3.0

1. Work on a feature branch, never directly on main.
2. Verify current committed version.
3. Replace/add only release files.
4. Run `git diff --check`.
5. Open `index.html` and test sidebar, search, filters and calculators.
6. Confirm no secrets/API keys.
7. Commit, push branch, review diff, then merge.
